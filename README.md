# 심준보 포트폴리오

이력서·포트폴리오·경력기술서와 체험형 전시관을 제공하는 공개 웹사이트입니다.

- 주소: https://jbsim999.github.io/junbo-portfolio-site/
- 일반형: `normal.html`
- 체험형: `game.html`
- PDF: `pdf/resume.pdf`, `pdf/portfolio.pdf`, `pdf/career.pdf`

이 저장소는 공개 배포 파일만 포함합니다. 개발 자료와 내부 검증 기록은 별도 비공개 저장소에서 관리합니다.

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

체험형은 불투명 유리 바닥의 이력서 전시와 밝은 해변의 프로젝트 낚시로 구성됩니다. 캐스팅·입질·챔질·끌어올리기·획득 동작, 물결/그림자/효과, 기기 내 수집 기록을 제공합니다. 낚시 도움은 기본 켬, 소리는 기본 끔이며 모든 프로젝트는 낚시 없이도 바로 읽을 수 있습니다.

PixiJS 8.21.0 이력서 환경, Canvas2D 해변/낚시, Anime.js 4.5.0 전환을 사용합니다. 글자와 컨트롤은 네이티브 HTML이며 그래픽 로딩 실패 시에도 문서 읽기가 가능합니다. 라이브러리 MIT 라이선스는 `vendor/`에 포함되어 있습니다.

길게 누르기 이동/카메라를 단일 프레임으로 정리했고, 낚시 맵은 40% 줄여 PC에서 세 어군이 함께 보입니다. 어군 영역/명암과 물고기 실루엣을 키우고 모바일 포인트 바로가기를 추가했습니다. 불투명 유리 바닥은 거리별 패널 원근을 적용했으며 파티션은 유리 면·프레임·상하 마감으로 완성했습니다.
